# FinalAssignment-Can-Femke
Final assignment of Algorithmic Decision Making course, MSc EOR. 

To run the simulation, open main.py and define your parameters in the main section. After that, press "Run Python File". This will ouput a .csv, which can then be directly opened using the resultvisual.Rmd file. 
When that file opens, press "run all" (ctrl+alt+R). This will generate the visualisations used in the report.
